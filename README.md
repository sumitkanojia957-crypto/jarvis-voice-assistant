# J.A.R.V.I.S – AI-Powered Voice Assistant

## Project Description

J.A.R.V.I.S is a Python-based AI-powered voice assistant that recognizes voice commands and performs tasks such as opening websites, playing music, retrieving news headlines, and generating intelligent responses using the OpenAI API.

## Features

- Wake-word detection using "Jarvis".
- Voice recognition and command processing.
- Website opening through voice commands.
- Music playback using predefined YouTube links.
- News headline retrieval using NewsAPI.
- AI-powered responses using OpenAI API.
- Text-to-speech responses.

## Technologies Used

- Python
- SpeechRecognition
- OpenAI API
- gTTS
- Pygame
- NewsAPI
- Webbrowser
- JSON

## Project Files

- `main.py` – Main voice assistant program.
- `client.py` – Text-based AI assistant.
- `musiclibrary.py` – Music links and library.

## Installation

1. Clone or download this repository.
2. Install the required Python packages.
3. Configure your API keys using environment variables.
4. Run the application using:

```bash
python main.py
```
